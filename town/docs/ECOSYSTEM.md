# 三邻邦 · 智能生态位（v1.4.0）

> 目标：帮 OPC 找到多元化经营路线。系统读取 OPC 的一切资料，自动生成它的上游、下游、供应链、横向合作与跨界方向，
> 按匹配度降序给 6 个；每个方向**生成即审核**，并用科学方法估算**市场价值（年营收，人民币）**。
> 代码：`src/domain/ecosystem.ts`（前端、离线版与后端 `POST /api/eco/niches` 共用同一套规则），测试：`src/domain/__tests__/ecosystem.test.ts`、`server/test/api.test.ts`。

## 一、读哪些资料

小店资料（店名、一句话介绍、营业范围、产品与说明、案例、正在找、FAQ、执照主体）＋ 生意画像（已确认的能力标签、行业、需求）＋ 上传资料提炼的公司介绍 / 产品介绍（正式版）＋ 自己在生态位页补充的业务简介。
资料先映射成能力标签（与「我的生意」同一套 taxonomy），**关系推理只在标签和知识库上做，不让大模型凭空编造**。【例】示范店不生成。

### 3 个小问题 + 自由补充（让匹配更准）

第一次打开时先问 3 个问题（约 20 秒），也可以随时「修改 / 补充」：
1. **你最拿手的是？**（选 1–3 个能力，已从资料里识别到的会标「识别」）→ 计入能力画像，在对应方向上权重 × 1.15
2. **你最想往哪拓展？**（都可以 / 找新客户 / 做上游供应 / 和同行联合 / 跨界新赛道）→ 关系类型一致的方向 +6 分
3. **你的生意能做多远？**（本地线下 / 全国线上 / 想出海）→ 本地方向 +5、全国可交付 +3、可出海 +6
4. **还想补充什么？**（营业范围、产品、公司介绍、手上的资源，选填）→ 并入资料一起提取能力与关键词

**开了店**：回答保存到店铺资料（`OpcProfile.eco`；正式版同步到服务器 `shops.eco_json`，通过 `PUT /api/shops/mine` 写入、`GET /api/shops/mine` 读回），换设备登录也在；只给店主自己用于匹配，不出现在公开店铺信息里，联系方式会被自动隐藏。**没开店**：先存在本机，开店后再保存一次即记到店铺。

## 二、生态位知识库

40 个方向（AI Agent 落地、AIGC 宣传片、微短剧外包、直播间代运营、剪辑外包、具身智能场景集成、出海内容、硬件打样、婚礼跟拍、银发数字课堂、非遗体验、企业节礼……），每个方向登记：
- 适配能力（能力标签 → 权重）、关键词、所属行业、一人适配度、重点城市、所需资质；
- 市场参数：潜在客户数、年渗透率、年频次、客单价、相关行业规模、细分占比、年复合增长、地域属性（本地 / 全国 / 可出海）、中国占全球比重、可触达比例、同赛道服务商数、一人年产能、数据口径。

## 三、匹配度（降序取 6）

匹配度 = 100 × (0.38 核心实力 + 0.12 资料命中 + 0.12 行业相关 + 0.18 赛道机会 + 0.12 一人适配 + 0.08 地域)^0.7，取 1–99。
- 核心实力：你的能力在该方向的权重（最强一项 + 0.2 × 第二项 + 0.1 × 第三项）
- 资料命中：方向关键词出现在你的资料里的比例
- 行业相关：行业关联度表
- 赛道机会：0.5 × 规模（1 亿 → 1000 亿 对数归一）+ 0.5 × 增速（40%/年 封顶）
- 地域：所在城市是不是这个方向的重点城市（如深圳 × 硬件、长沙 × 直播）
关系类型：能力延伸 / 横向合作 / 上游供应链 / 下游客户 / 跨界多元。

**丢弃 → 补位**：点「不感兴趣」，从候选池里补上下一名。**收藏 → 收藏夹**：方向移入收藏夹（可加预设或自定义标签、按标签筛选），推荐位同样补上新的。

## 四、审核（生成即审核，不通过不展示）

| 检查 | 规则 | 结果 |
|------|------|------|
| 合规红线 | 刷量、刷单、控评、网贷、套现、博彩、传销、洗钱、代考等 | 不通过，永不展示（页面显示“审核已拦截 N 个”） |
| 经营资质 | 食品、旅游、营运车辆等需许可 | 通过但标「需资质」，写明需要什么 |
| 估算可信度 | 两种算法相差 > 3 倍 | 不通过（数据不一致） |
| 一人可交付 | 一人适配度 < 0.5 | 提示找搭档 |
| 数据来源 | 必须有可追溯口径 | 没有则不通过 |

## 五、市场价值（年营收，人民币）

1. **自下而上**：潜在客户数 × 年渗透率 × 年频次 × 客单价
2. **自上而下**：相关行业年规模 × 细分服务占比
3. **三角验证**：市场规模 TAM = √(自下而上 × 自上而下)，并给出两者差距倍数与可信度（≤1.5 高 / ≤3 中）
4. **范围**：默认中国；必须线下交付的方向按本城市占全国比重折算并标「📍 本城市」（GDP 或社会消费品零售总额口径：上海 4.0% / 3.7%，北京 3.7% / 2.9%，深圳 2.7% / 2.3%，长沙 1.1% / 1.1%，成都 1.7% / 2.2%）；可出海的方向可切换「🌍 全球」= 中国规模 ÷ 中国占全球比重
5. **可服务市场 SAM** = TAM × 小微服务商可触达比例
6. **你 3 年可获得 SOM** = min(SAM ÷ 同赛道服务商数 × 竞争力系数(0.5 + 匹配得分)，一人年产能 × 客单价)
7. 另给 3 年后市场规模 = TAM × (1 + 年复合增长)³

参数取国家统计局、海关总署、民政部、文旅部、行业协会与主流研究机构公开数据的约 2024 年量级（取整），单测保证所有可展示方向两种算法相差不超过 2 倍。用于方向判断，不构成投资建议；后台可随时更新参数表。

## 六、测试链路

1. 底部「产业链」→ 默认「✨ 智能生态位」。
2. 回答 3 个小问题（拿手：摄影；方向：找新客户；范围：全国线上），补充「武康路摄影工作室，拍产品图和短视频，也做品牌宣传片和直播切片」→「保存并重新匹配」→ 已开店时提示「已记到『店名』的店铺资料里」→ 看到 6 张卡片，匹配度从高到低，每张有「✅ 已审核」或「⚠️ 已审核 · 需资质」、关系类型、市场规模 / 可服务市场 / 你 3 年可获得。
3. 点「🧮 怎么算的」：匹配度六项得分、市场价值 8 步计算、审核记录。
4. 点「🗑 不感兴趣」：这张消失，补上一个新方向，仍是 6 个。
5. 点「⭐ 收藏」：进入下方「我的收藏夹」，推荐位补上新的；在收藏卡片上加「#先试试」或自定义标签「明年做」，按标签筛选。
6. 可出海的方向点「🌍 全球」，市场规模变大；本地方向显示「📍 上海」并标注需要本地交付。
7. 写「直播带货主播，做直播间场控」→ 底部显示「🛡️ 审核已拦截 1 个不合规方向（直播间刷量与控评）」。
8. 「🔗 产业链黄页」切回原来的三条产业链。
