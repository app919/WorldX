## MVP 必须砍掉的功能

全上海地图、真实人流模拟、50–500 个 AI 玩家、全套物理碰撞、自建支付、完整供应链管理、
自动签约与自动谈判、复杂虚拟货币经济、3D 建筑实时编辑器、AI 自动修改并发布生产代码。

## MVP 验收标准（第一轮目标，不是现有表现）

| 指标 | 目标 | 当前如何验证 |
| --- | --- | --- |
| 新用户首次进入成功率 | ≥ 95% | e2e「首次进入成功」 |
| 三分钟内完成新手任务 | ≥ 80% | 新手小任务进度（需线上埋点） |
| 地图稳定帧率 | ≥ 30 FPS | 需真机测试；CI 容器无 GPU，仅软件渲染参考 |
| OPC 创建成功率 | ≥ 95% | e2e 开店流程 |
| Agent 基础问答准确率 | ≥ 90%（测试集） | `agent.test.ts`，需扩充测试集 |
| 推荐关系可解释率 | 100% | 每条关系必有 reasons + breakdown（单测 + e2e） |
| 商务打招呼送达率 | ≥ 98% | 需服务端埋点 |
| 关键订单状态一致性 | 100% | 订单模块上线后加入 |

## 自动化测试闭环（安全版 Self-Healing）

```
代码提交 → 生成测试 → 虚拟玩家执行 → Observer 监控
  → 通过：保存截图与日志
  → 失败：Repair Agent 分析 → 生成补丁 → 沙盒回归 → 人工审核 PR → 测试环境 → 发布审批
```

不允许 AI Agent 在生产环境自动修改代码、自动合并和发布。

测试画像：上班牛马（通勤/碰撞）、闲逛玩家（建筑/动画/交互）、OPC 主理人（开店/改价）、
商务采购商（询价/下单）、社区组织者（活动/会议）、混沌破坏者（极限输入/断网/重复点击）。
测试角色不得混入真实用户的社交与交易统计。

当前已落地：`npm test`（37 个领域单测）+ `npm run e2e`（演示故事 8 项验收 + 13 张截图）。
