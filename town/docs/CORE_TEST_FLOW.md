# 三邻邦 · 核心功能测试链路（v1.3.1）

> 按顺序走一遍即可覆盖全部核心功能。每一步写了“怎么做”和“应该看到什么”。
> 离线演示版（网页 / 离线 HTML）不需要登录，从第一章开始；正式版（后端）先做第十章的注册登录。

---

## 一、进入三邻邦

1. 打开页面 → 看到「选一个身份」：投资人 / 在职看副业 / OPC 主理人 / 商业服务者 / 品牌方 / 游客。
   - 点不同身份，左边 3D 小人的着装跟着变：投资人黑西装、品牌方金夹克、其他身份紫色系（背带裤 / 衬衫工牌 / 马甲 / T 恤背包）。
   - 切换「女生 / 男生」，发型变化；换发色。
2. 选「OPC 主理人」→ 下一步 → 看到 5 座城市（上海 / 北京 / 深圳 / 长沙 / 成都）和每座城市的街道列表。
   - 点「北京」，列表里有南锣鼓巷、帽儿胡同、雨儿胡同、菊儿胡同、东棉花胡同等。
   - 选「上海 · 武康路」→「出发，去我的街区」→ 角色出现在武康路上。
3. 其他身份（如「游客」）的第二步：「直接进入上海（默认）」或点任意城市进入。

## 二、街区与画面

1. 顶部「🏙️ 上海 ▾」切换城市，右边是该城市的街区（上海三个：武康大楼 / 洋泾社区 / 甜爱路及四川北路）。
2. 路名、公园名为真实名称：武康大楼的淮海中路、武康路、天平路、兴国路、安福路，襄阳公园、徐家汇公园；洋泾的张杨路、源深路、羽山路，泾南公园、源深体育中心……
3. 建筑风格：北京四合院（灰砖灰瓦红门）、深圳玻璃塔楼、长沙马头墙、成都川西民居；鼓楼、赛格广场、贾谊故居、大慈寺、IFS 等地标。
4. 屋顶颜色 = 店铺是谁开的：**粉 = 【例】系统示范店**，**蓝 = 【企】有执照的公司**，**黑 = 【投】投资机构**，**金 = 【品】品牌 / 黄金位赞助商**，**紫 = 个人开的店**；空铺（招租位、待赞助的黄金位）是原来的屋顶颜色。小地图下方有图例。
5. 空铺：黄金位与 OPC 招租位在街上交错分布（每 5 个铺位里约 2 个黄金位），不会一出门全是黄金位。
6. 左下角工具条：＋ / － 缩放镜头（也可以滚轮、双指捏合、键盘 + -）、「📰 街区动态」；小地图的 ＋ / － 放大并以自己为中心。
7. 红绿灯、斑马线：只能走人行道，红灯不能过马路；车辆有轿车、两厢、SUV、出租车、MPV、迷你电动车、快递车；车辆不会撞人。
8. 右上角：城市 + 当地时间（东八区实时）+ 当地天气（晴 / 阴 / 雨 / 雪）；点时间可以暂停预览昼夜，再点回到当地时间。

## 三、右上角：等级与星星

1. 右上角只有一个「Lv.1 新邻居 ▬ ⭐星星」。点开：当前经验、升到下一级还差多少、解锁什么；说明经验 = 星星 + 成长值 × 3；不能兑换人民币。
2. 没在打工时看不到 💴 钞票 / ⚡ 体力；接了打工任务才出现。

## 四、新手 7 天 · 签到 · 每日委托

1. 左上角任务面板：第 1 天的 3 件小事（图标 🎯 / 👀 / 🎪 区分类型），每件有提示。
2. 做完任意一件（例如走进一家粉色屋顶的【例】示范店）→ 弹出「任务达成」→ 面板里点「领取 ⭐」→ 星星增加；三件都领完得当天徽章。
3. 面板底部签到条：「连续 N 天 · 第 1 季 x/30」，第 3 / 7 / 14 / 21 / 30 天有里程碑奖励。每天第一次进来自动签到。
4. 第 2–7 天的任务按自然日解锁（锁住的天显示 🔒）；第 8 天进来：「新手毕业」⭐ +60 + 徽章，之后变成「每日委托」（每天 3 件，0 点刷新；周一、周四会有“去本周主题城市逛逛”）。
5. 离开超过 8 小时再回来：弹出「欢迎回来！你不在的 X 小时里：……」（谁回复了你的需求、动态更新条数、本周主题城市、连续签到、今天的委托）。

## 五、今天来找什么 → 打个飞的 → 店铺

1. 右下角搜索框点「找拍摄」（或输入后回车）→ 列出结果，每条显示：评价分、⭐评分（条数）、信用等级、活跃度、在线 / 离线；**按评价分从高到低**；【例】示范店排在最后。
2. 点「✈️ 打个飞的」（或再按一次回车，直接去第一名）：
   - 小飞机载着角色起飞 → 整屏穿越云层（小飞机飞过云海）→ 云层散开、从天而降落在店门口 → 顶部「✈️ 我们到了！店名」。
   - 落地后自动打开店铺 AI 分身。
3. 跨城市搜索（如在上海搜「找具身智能」）→ 打个飞的 → 直接落到深圳 / 北京对应的店门口。
4. 「找投资人」→ 点结果 → 打开服务中心「融资资源」。

## 六、店铺 AI 分身 → 聊一聊 → 合作

1. 店铺面板：产品与价格、信用记录、产业链位置、正在寻找；点快捷问题（多少钱 / 有案例吗 / 你是真人吗）→ AI 分身回答并标注 L1 / L2。
2. 店主**在线**（如「光影小棚」）：点「💬 聊一聊（在线）」→ 发一句话 → 收到店主回复（演示回复）→ 店铺上方冒出 💗，之后一直有跳动的小爱心。
3. 点「🤝 达成初步合作意向」→ 全屏小礼花 + 「🎉 和「店名」达成初步合作」，消息里有一条通知。
4. 店主**不在线**（如「梧桐豆子」）：「聊一聊（留需求）」→ 填做什么 / 预算 / 时间 / 线上线下 → 发送 → 提示“对方上线后会在「消息」里收到”；「消息」里有“已把需求发给…”。
5. 晚上（9:00–18:00 以外）聊天：窗口顶部提示非工作时间，但消息照常可以发。
6. 走开就收起：在店门口打开信息牌 / 店铺面板后，往前或往后走几步，面板自动收起；**也可以点右上角 ✕ 关掉，关掉后站在门口不会马上又弹出来**。
7. 【例】示范店：完整资料（公司简介、主理人、亮点、产品与价格、服务流程、案例、工具、FAQ、正在寻找），「聊一聊」不可用（系统示范，无法交易）；产业链里查不到【例】。

## 七、街区动态与活动现场

1. 左下角「📰 街区动态」→ 跨城市的上新、交付、开播、活动，每条可以「✈️ 打个飞的」过去。
2. 每个街区都有一场正在进行的活动：街上有摊位和围观人群，头顶活动牌「● 进行中 · N 人在看 · M/容量 已报名」。
3. 点活动牌（或从动态飞过去）→ 活动现场：围观人数、报名人数、弹幕；发一条弹幕 → 出现在弹幕里；「我要报名」→ 已报名。

## 八、开店与铺位规则

1. 走到 OPC 招租位门口 → 招租名片（含 60% OPC / 40% 黄金位说明）→ 开一家小店：外观、铺位、商品与价格、正在找、主体（有执照填企业名称 + 统一社会信用代码，校验位不对会拦截）、AI 分身权限 L1 / L2 / L3。
2. 开店后再去另一个空铺 → 只提示“你已经有一家小店”，不能再开（一人一店）。
3. 走到黄金位门口 → 赞助招商 → 资质校验（信用代码错误会拦截）→ 提交 → 审核 → 付款 → 上线（招牌带「赞」，屋顶金色）。
4. 「我的小店」→ 进入自己的店，试用自己的 AI 分身。

## 九、对接与成交（机会 / 产业链 / 服务中心 / 社区）

1. 「我的生意」：输入一句话 → AI 提取能力标签 → 确认 → 五类关系（客户 / 供应商 / 合作 / 渠道 / 资源），每张卡片有推荐理由与计算依据。
2. 「产业链」：电商直播出海 / 非遗手艺 / 教育培训三条链；选环节 → 登记到黄页 → 速配上游、下游、同行、服务商；服务商展位每环节 2 个。
3. 「机会」：需求大厅（字段：需求方 / 预算 / 交付 / 地区 / 合作方式 / 截止 / 状态）；发布需求（含违规拦截）→ 平台推荐 → 比选表 → 选标 → 成交确认单（双方确认时放礼花）→ 按节点验收 → 评价 → 复购；推广接单、兼职投递、联合交付组队。
4. 「服务中心」：创业服务市场（套餐比价、预约）、信用与保障、交易型活动、会员与价格、融资资源、案例论坛。
5. 「我的社区」：活动报名、发起活动。
6. 「打工」：告示板接单 → 跑腿取货送达 / 帮工 → 挣钞票（只用于游戏内消费）。

## 十、正式版后端（需要启动服务）

1. 启动：`cd town && npm install && ADMIN_PHONES=13900000000 npm start` → 打开 http://localhost:8787 。
2. 注册登录：勾选协议 → 手机号 + 验证码（开发模式验证码显示在登录框下方）登录；或微信扫码（开发模式点「确认登录」）。
3. 开店上传 PPT / PDF / Word → 自动提炼公司简介 / 产品简介；资料里的手机号、微信号被隐藏。
4. 另一个账号走进这家店 → 看到提炼的简介 → 发私信 → 店主收到（对方手机号被隐藏）→ 回复 → 对方收到；「留微信号」按钮点击被记录。
5. 刷新页面：仍然登录，小店与进度都在。
6. 管理员（13900000000）打开 http://localhost:8787/admin.html：注册用户、活跃用户、PV / UV、各模块与按钮的点击、留微信号点击、消息审查（查看会写入审计日志）；普通用户访问管理接口被拒绝。
7. 天气：服务器能访问 api.open-meteo.com 时，每天凌晨 3 点自动更新第二天各城市天气；`/api/weather` 返回今天的天气。

## 十一、手机
