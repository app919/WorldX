# 三邻邦 · 「买 · 逛 · 跟」需求梳理与链路检查（v1.2.0）

三类用户心智，对应三种不同的设计原则：

| 类型 | 用户在想什么 | 设计原则 | 检查标准 |
|------|--------------|----------|----------|
| **买** | 我有明确需求（找剪辑、找拍摄、找投资人……） | **效率**：最少步骤、最快响应、直接到人 | 从打开到和对的人说上话 ≤ 3 步；结果按靠谱程度排序；不在线也能把需求留下 |
| **逛** | 我想看看大家在做什么 | **有趣**：有画面、有变化、能“飞”来飞去 | 每次来都有新东西；任何看到的东西都能一点就到现场 |
| **跟** | 我想凑热闹、参加活动、认识人 | **氛围**：集市感、人气、参与感 | 能看到多少人在看 / 报了名；一键围观、报名、发弹幕；有庆祝反馈 |

---

## 一、功能归类

### 买（明确需求 → 高效检索 → 对接 → 成交）

| 功能 | 入口 | 说明 |
|------|------|------|
| 今天来找什么（需求框） | 右下角 | 快捷词 + 同义词扩展；结果覆盖入驻店铺、真实用户店铺、服务商、投资人 /园区 /专家、【例】 |
| 按评价分排序 | 需求框结果 | 评价分 = 评分×10 + 信用分×0.3 + 活跃度×0.2；显示评分、信用等级（AAA/AA/A/B/新）、活跃度、在线状态；【例】不可交易，排最后 |
| 打个飞的 | 结果上的 ✈️ / 回车两次 | 1 秒动画后落在店门口，直接打开店铺 AI 分身；跨城市也一样 |
| 店铺 AI 分身 | 进店 | L1 答疑 / L2 预约 / L3 本人确认；价格只引用主理人确认的资料 |
| 聊一聊 | 店铺内 | 店主在线：直接聊；不在线：写下需求（做什么 / 预算 / 时间 / 线上线下）发给对方，对方上线在「消息」收到；非工作时间照常可发 |
| 达成初步合作意向 | 聊一聊 | 放礼花庆祝，写入消息，下一步引导到需求单 / 成交确认单 |
| 需求大厅（发布 → 审核 → 匹配 → 比选 → 成交 → 交付 → 评价） | 底部「机会」 | 成交确认单双方确认时放礼花 |
| 我的生意（客户优先速配） | 底部 | 五类关系、推荐理由 |
| 产业链速配 | 底部「产业链」 | 上游 / 下游 / 同环节 / 服务商 |
| 服务中心（服务商、投资人） | 右上角 | 套餐比价、预约 |
| 私信（真实用户） | 店铺 / 消息 | 手机号、微信自动隐藏 |

### 逛（看大家在做什么 → 有趣 → 一点就到）

| 功能 | 说明 |
|------|------|
| 7 个街区、5 座城市 | 上海（武康大楼 / 洋泾 / 甜爱路及四川北路）、北京南锣鼓巷、深圳华强北、长沙五一商圈、成都春熙路 · 太古里；真实路名与公园名；各城市建筑特色（四合院、玻璃塔楼、马头墙、川西民居、鼓楼 / 大慈寺） |
| 城市切换 | 顶部「🏙️ 城市 ▾」；身份不同出发预设不同（OPC 选公司所在城市与街道，其他人选感兴趣的城市或默认上海） |
| 【例】示范店（每街区 10%） | 粉色屋顶 + 粉色背带裤主理人；完整资料；不可交易、不进产业链 |
| 全站身份色 | 例 粉 / 企 蓝 / 投 黑 / 品 金 / 其他 紫：屋顶、角标、服装、小地图一致 |
| 街区动态 📰 | 左侧「动态」：上新、交付、开播、活动；每 10 分钟换一批；点一下飞过去 |
| 当地时间昼夜 + 真实天气 | 东八区实时昼夜；每天凌晨 3 点查第二天预报，取时间最长的天气（晴 / 阴 / 雨 / 雪） |
| 随便逛逛、镜头 / 小地图缩放、地标档案 | |
| 对聊爱心 | 有对聊的店铺上方一直有跳动的小爱心，达成合作再加 🎉 |

### 跟（社区、集市、人气）

| 功能 | 说明 |
|------|------|
| 正在进行的活动（每个街区至少一场） | 街上有摊位 + 围观人群 + 活动牌「● 进行中 · N 人在看 · M/容量 已报名」 |
| 活动现场 | 围观人数、报名人数、弹幕（可以发）、一键报名、跳到活动详情 |
| 社区活动 | 报名、发起活动、流程与规则 |
| 新手 7 天任务 | 六种身份 × 7 天 × 3 件事（买 / 逛 / 跟），奖励星星、成长值、每日徽章 |
| 礼花庆祝 | 初步合作、合作记录双方确认、成交确认单双方确认 |
| 论坛 / 案例 | 服务中心 |

## 二、链路检查（按原则逐条）

| # | 链路 | 原则 | 检查结果 |
|---|------|------|----------|
| 买-1 | 搜索 → 结果 | 效率 | ✅ 本地即时检索，无网络等待；快捷词一点即出；同义词扩展避免“搜不到” |
| 买-2 | 结果 → 选人 | 效率 | ✅ 按评价分排序，显示评分 / 信用 / 活跃 / 在线，【例】排最后；（本版修正：之前按相关度排，【例】可能排在前面） |
| 买-3 | 选人 → 到店 | 效率 | ✅ 打个飞的 1 秒到门口并自动打开店铺；回车两次直接飞到评价分最高的可交易店铺（本版新增） |
| 买-4 | 到店 → 说上话 | 效率 | ✅ 「聊一聊」：在线直接聊，不在线留需求（本版新增）；以前只能“打招呼”等对方同意 |
| 买-5 | 夜里找人 | 效率 | ✅ 非工作时间提示但不拦截；双方在线照常聊 |
| 买-6 | 说上话 → 合作 | 效率 + 反馈 | ✅ 一键「达成初步合作意向」+ 礼花；下一步引导到需求单 / 成交确认单 |
| 买-7 | 隐私 | 合规 | ✅ 需求表单提示不要写手机号 / 微信；真实私信自动隐藏联系方式 |
| 逛-1 | 进入 → 看到有趣的东西 | 有趣 | ✅ 出生点附近就有【例】示范店（粉色）、活动人群、公告栏 |
| 逛-2 | 看到 → 到现场 | 有趣 | ✅ 动态、活动、搜索结果都能“飞过去” |
| 逛-3 | 每天都不一样 | 有趣 | ✅ 真实昼夜与天气；动态每 10 分钟换一批；新手任务每天不同 |
| 逛-4 | 认得出谁是谁 | 有趣 | ✅ 全站身份色（屋顶 = 服装 = 角标） |
| 跟-1 | 看到人气 | 氛围 | ✅ 活动牌显示围观 / 报名人数（演示数据标注“演示”，正式按真实统计） |
| 跟-2 | 参与 | 氛围 | ✅ 围观、弹幕、报名一步完成 |
| 跟-3 | 被庆祝 | 氛围 | ✅ 爱心、礼花、每日徽章 |
| 跟-4 | 留存 | 氛围 | ✅ 7 天任务；第 N 天在第 N 个自然日解锁，已解锁的可补做 |

## 三、数据看板（管理后台）

新增的关键动作都会进入后台「模块 / 点击」统计：`buy`（打个飞的、聊一聊在线 / 离线、留需求、达成意向）、`need_box`（搜索词、点了第几名）、`browse`（动态、换城市）、`follow`（围观、报名、庆祝）、`quest`（领取任务）。可以据此看三条链路的转化。

## 四、仍需正式环境配合

- 天气：服务器需能访问 `api.open-meteo.com`（免费、无需密钥）；访问不到时默认晴天。
- 评价分：演示数据为模拟值；正式上线后用真实评分、信用分、近 7 天活跃度计算。
- 围观 / 报名人数：正式上线后按真实围观、报名统计。
- 真实用户之间的「聊一聊」走后端私信；演示店主的回复是模拟的（标注“演示回复”）。
