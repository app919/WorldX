# 三邻邦 · 需求核对（v0.5.0）

“三邻”：街坊邻里（同一条街）· 上下游邻居（同一条产业链）· 同行邻伴（同一个环节，可以联合接单）。

| # | 需求 | 状态 | 在哪里 / 怎么做的 |
|---|------|------|------------------|
| 1 | 每个 OPC 可以建店，展示产品或能力 | ✅ 已满足（本版加强） | 空铺「开一家小店」：外观、铺位、商品 / 服务与价格、正在找的资源、主体类型、AI 分身权限（L1/L2/L3）。店里展示商品、案例、FAQ、正在寻找；**新增**：店铺显示「产业链位置」，点一下跳到链路图。 |
| 2 | 上下游速配 / 智能匹配（黄页 + 供应链结构） | ✅ 本版新增「🔗 产业链」 | 三条行业链的完整链路图（上游 / 中游 / 下游 / 服务支撑，箭头写明流动的是货、素材、订单还是学员）；每个环节是一页黄页（成员、能提供、正在找、所在街道或城市）；系统根据商业画像 / 小店自动把“我”放到环节上（也可手动登记）；**速配**按链上流向找出上游供货、下游客户、同环节伙伴、服务商，并写明理由；**缺口**提示“招募中”。原有「我的生意」五类关系（客户 / 供应商 / 合作 / 渠道 / 资源）保留。 |

## 帮你补充的（没想完的部分）

1. **按能力推荐机会**：每条公告显示“与你匹配 X%”（能力标签 + 是否在你所在 / 相邻的环节）。
2. **发布审核规则**：标题、预算 / 报酬、截止必填；拦截“刷单、刷评、保证金、押金、培训费、先交钱、包过”等内容。
3. **推广合规**：推广内容必须标注「广告 / 推广」，不得虚假宣传；佣金按验收结果结算。
4. **灵活用工说明**：不构成劳动关系、按次 / 按小时结算、注意人身安全、收入按规定申报个税。
5. **交易边界**：合同、报价确认、付款属于 L3，必须本人确认；演示版平台不代收款、不担保交易。
6. **信用记录**：只来自双方确认完成的合作，不能刷。
7. **我的进度**：我发布的案子与收到的投标、我的投标、我接的推广、我投递的岗位，一处看全。
8. **产业链缺口 → 补位**：缺口环节可以一键登记补位，商家也可以针对缺口发招标。

## 后续建议（下一版）

- 招标的里程碑与验收节点、双方评价；
- 服务商资质核验（营业执照 / 行业许可）后才能抢位，正式版按展位期收费并在页面上公示规则；
- 推广码的真实成交追踪（需接入商家的订单系统）；
- 机会广场的“附近”视图：把公告标在 3D 街区对应的店门口；
- 行业链可扩展：用同一套数据结构增加咖啡、婚庆、社区生活等行业。
