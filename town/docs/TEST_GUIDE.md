# 三邻邦（OPC Town）· 测试链路与检验标准（v0.8.0）

> 打开方式：在线链接，或下载包里双击「三邻邦.html」。顶栏左上角应显示「三邻邦（OPC Town）」与版本号 **v0.8.0**。
> 想从头测：「我的」→「重置演示数据」。
> 全部为演示数据（虚构主体），平台不收款、不代收款。

每一条写成：**怎么操作 → 应该看到什么（检验标准）**。括号里是自动化走查（e2e/full-playtest.cjs）对应的步骤。

## A. 进入与基础（街区可玩性）

| # | 操作 | 检验标准 |
|---|------|---------|
| A1 | 首次打开，选生活标签、衣服颜色、昵称，选一条街进入 | 6 种标签可选；三条街（武康大楼 / 洋泾社区 / 甜爱路及四川北路）都能作为出发点（引导） |
| A2 | WASD / 点击地面 / 「随便逛逛」 | 只走人行道，从斑马线过马路；撞到车道会提示；点击地面自动寻路 |
| A3 | 看路上的车 | 车辆不会互相穿过；转弯走弧线；在地图边缘驶入 / 驶出隧道，不会开出地图 |
| A4 | 走到树下、楼后 | 能看到自己的剪影和脚下橙色光圈；小地图上「📍 找到我」或按 F，镜头回到自己 |
| A6 | 走到路口看红绿灯 | 每个路口每个方向一根 L 形信号灯（红 / 黄 / 绿），各方向轮流放行；车辆红灯在停止线前停、绿灯通行，不闯红灯 |
| A7 | 在路口斑马线前等红灯，再在绿灯时过马路 | 斑马线两端有行人信号灯；行人红灯时走不上斑马线（提示“红灯，请等行人绿灯”），绿灯可以过；路人也会等灯 |
| A8 | 站到车道上 / 斑马线中间，看车 | 车辆在你前方刹停，不会压过去；没有信号灯的斑马线，有车驶来时先等车过 |
| A9 | 沿人行道直直走向行道树、路灯、单车停放区 | 会自动沿边缘绕过去，不会卡在树前或被困在缝隙里 |
| A5 | 看小地图 | 有路名、公园名（🌳）、绿点 = OPC 招租位、金点 = 黄金赞助位 |

## B. 开店规则（本版新增）

| # | 操作 | 检验标准 |
|---|------|---------|
| B1 | 「我的生意」→ 任一步骤或小地图看铺位分布 | 每个街区：黄金位 = 铺位总数 × 40%（四舍五入），其余为 OPC 招租位（60%）；已有店铺不占黄金位（铺位规则） |
| B2 | 走到金色招牌「黄金位 · 赞助招商」的门口 | 弹出「黄金位 · 赞助招商」名片，说明 60/40 规则；**没有**“在这里开店”按钮 |
| B3 | 在黄金位点「申请赞助」，填企业全称、错误的信用代码（如 91310000MA1FL0000A） | 提示“统一社会信用代码不正确” |
| B4 | 改为正确代码（如 91310000MA1FL0000 + 校验位，可用自动化脚本里的 uscc 函数生成）后提交 | 状态依次：资质审核中 → 待对公付款 → 已上线；招牌变成赞助商名并带「赞」角标（黄金位） |
| B5 | 走到「OPC 招租」铺位门口 | 名片写明 OPC 招租位、“有没有营业执照都可以开店”、本街区 60/40 数量（空铺） |
| B6 | 点「在这里开店」，店主用已存在的身份：林小满 / 13800000001 | 下一步被拦：“手机号已经开过店了”“姓名已经登记过店铺”（开店） |
| B7 | 换成自己的姓名 + 新手机号，验证码填错 | 提示“验证码不正确”；填演示验证码后才能下一步 |
| B8 | 铺位下拉框 | 只有 OPC 招租位，没有黄金位 |
| B9 | 第三步选「我有营业执照」，信用代码填错 → 再填对 | 填错被拦；填对可继续 |
| B10 | 开张后看自己的店招牌与店铺面板 | 招牌左上角红色「企」角标；面板标题旁「企」；显示店主姓名和脱敏手机号（139****5678）（我的小店） |
| B11 | 选「暂无营业执照」开店（重置后测） | 可以正常开店，没有「企」角标 |
| B12 | 已有小店后再走到别的空铺 | 只提示“你已经有一家小店”，不能再开（每人一家店） |
| B13 | 看街上其他店 | 有执照的店（如梧桐豆子、小步营销、街角书店）带「企」；无执照的个人主页（如光影小棚、甜爱文创）没有 |

## C. 商业连接：需求单交易链（PPT 核心流程：发布 → 审核 → 匹配 → 对接 → 成交 → 履约 → 评价）

| # | 操作 | 检验标准 |
|---|------|---------|
| C1 | 底部「📋 机会」→ 需求大厅 | 每张需求单都有：需求方身份（✔已认证）｜预算｜交付时间｜地区｜合作方式｜截止｜状态；可按类型 / 行业 / 地区 / 合作方式 / 预算筛选，按匹配度 / 最新 / 预算排序，「只看适合我」（需求大厅） |
| C2 | 先在「我的生意」用一句话建立商业画像（如“我会拍短视频和剪辑”） | 大厅里出现“与你匹配 X%”，并提示有 N 条需求与你匹配 |
| C3 | **供给方**：在「东南亚海外店铺代运营」点投标，填报价 / 工期 / 方案 | 卡片变“已投标 · 进入比选”，几秒后“中标 🎉” |
| C4 | 「我承接的」→ 成交确认单 → 本人确认成交（L3） | 显示甲方 / 乙方 / 金额 / 交付范围 / 3 个付款节点（30/40/30），双方确认后进度条到「成交」再到「履约」 |
| C5 | 逐个点「提交交付」 | 每个节点被对方验收，显示“已按节点结算 ¥x / ¥y（平台不代收）” |
| C6 | 全部验收后评价 | 可以打星、选标签；低于 2 星必须写原因；能看到对方给你的评价（供给方） |
| C7 | **联合交付**：在「AI 办公提效企业内训」点「组队联合投标」 | 系统按角色（课程设计 / 主讲讲师 / 课件视频）推荐人选；邀请后显示“已加入”；分成合计不是 100% 不能提交；提交后卡片“已投标”（联合交付） |
| C8 | **需求方**：「＋ 发布需求」，标题里写“需先交保证金” | 被拦截：“内容包含不允许的要求”（需求方） |
| C9 | 正常发布一条招标（可写角色：拍摄、设计） | 进度：审核中 → 匹配中；出现“平台为你推荐的供给方”（3 位，含理由 / 信用） |
| C10 | 点「邀请投标」 | 比选表出现投标：报价 / 工期 / 信用（★、单数、准时率、✔认证）/ 标记（报价最低、工期最短、信用最好、联合团队） |
| C11 | 选标 → 确认成交单 → 逐个「验收」 → 评价 → 「再次合作（复购）」 | 走完 7 步；复购生成一条【复购】新需求并自动邀请原合作方 |
| C12 | 回到街区 | 发布方店门口有蓝色需求标记（📣 ¥4–8k · 匹配中），点击打开需求大厅；成交后我和合作方之间出现金色连接线 |

## E. 产业链黄页 + 上下游速配

| # | 操作 | 检验标准 |
|---|------|---------|
| E1 | 底部「🔗 产业链」，依次切换 电商 · 直播带货及出海 / 非遗手艺 / 教育培训 | 每条链 7 个环节：上游 / 中游 / 下游 + 服务支撑；箭头上写明流动的是什么（货品、素材、订单、学员…）（产业链） |
| E2 | 看环节卡片 | 成员按类型着色（平台 OPC / 入驻商家 / 个人 / 未入驻 / 企业服务商）；平台内没人的环节标“招募中”；底部列出缺口 |
| E3 | 点「产品与内容生产」→「我也在这个环节」 | 链路图上出现橙色「⭐ 我」；右侧速配给出上游 / 下游 / 同环节 / 服务商，并写明理由与匹配分 |
| E4 | 黄页里点「去街区找 TA」 | 切换到对应街区并走到那家店门口 |
| E5 | 在某环节「⚡ 抢位提供资源」 | 未满的环节可以抢到（显示“我的展位 · 剩 7 天”）；满员环节（如电商 · 服务支撑）只能候补；展位标注推广，不影响匹配分 |
| E6 | 进店（如梧桐豆子） | 店铺面板显示「产业链位置」和「信用记录」（★、完成单数、准时率） |

## F. 社区、消息、我的（原有功能回归）

| # | 操作 | 检验标准 |
|---|------|---------|
| F1 | 进店与 AI 分身：6 个快捷问题 | 每个回答带 L1 / L2 / L3 标记；报价、折扣、合同类问题转交主理人 |

| F7 | 手机（或浏览器缩到手机宽度） | 底部弹层可用、摇杆能走、页面不横向溢出 |
